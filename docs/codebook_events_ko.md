# 구두개입 사건 코딩북 (v0.2, 파일럿)

## 1. 사건의 정의
**포함**: 다음 주체가 **공개적으로** 원/달러 환율의 수준·속도·변동성·쏠림·투기에 대해 언급하거나 대응 의지를 밝힌 발언·문서.
- 재정경제부/기획재정부/재정경제부(2026~): 장관(부총리), 차관, 차관보(국제경제관리관), 국제금융(정책)국장, 외화자금과장
- 한국은행: 총재, 부총재, 국제국장, 외환시장팀장
- 기재부·한은 **공동 명의 메시지**("외환당국"), F4(거시경제·금융현안 간담회) 결과문 중 환율 언급
- 대통령실·대통령: 환율을 명시적으로 언급한 경우에 한정

**제외**: 민간 금융기관·연구기관 의견, 외환보유액·외채만 언급한 발언, 일반 경기 발언, 익명 "시장 관계자" 코멘트. 익명 "외환당국 관계자" 코멘트는 포함하되 `official=N`.

## 2. 변수
| 변수 | 정의 |
|---|---|
| `date` | 발언일(KST). 기사 게재일과 다르면 발언일. 월만 알려진 경우 1일로 두고 `notes`에 PLACEHOLDER 표기 → 분석에서 제외 |
| `time_kst` | 발언 시각(HH:MM). 장중 효과 분리에 필수 |
| `speaker`, `title`, `institution` | 발언자·직위·기관 |
| `statement` | 원문 인용(가능한 한 축어). 요지·헤드라인 인용은 `[요지]`, `[헤드라인 인용]` 표기 |
| `direction` | `curb_depreciation`(원화 약세 억제), `curb_appreciation`(원화 강세 억제), `two_sided`, `unclear` |
| `intensity` | 1 우려·예의주시 / 2 대응 의지("필요시 조치") / 3 구체 조치·공동 메시지·명시적 경고 |
| `joint` | 기재부·한은 공동(같은 날 조율된) 메시지 여부 |
| `official` | 언론이 "공식 구두개입"으로 보도했거나 공식 입장문·보도자료인 경우 Y; 기자 질의응답·국회 답변 등은 N |
| `actual_intervention_reported` | 당일 실개입(달러 매도·매수 추정) 보도 Y/N/U |
| `usdkrw_level` | 발언 시점의 환율(기사 인용). **발언 직전 수준**이 핵심 |
| `source_urls` | 출처 URL(복수) |
| `confidence` | high(원문·날짜 모두 확인) / medium(날짜 확인, 문구 요지) / low(기억·헤드라인·추정) |

## 3. 처리 규칙(03_events.py)
- 같은 날·같은 방향의 복수 발언은 1개 사건으로 통합(강도=최대, joint/official=any).
- 비거래일 사건은 다음 거래일로 이동(`date_shifted=True`).
- 군집: 같은 방향 사건 간 간격이 g거래일 이하이면 같은 군집(g=3,5,10). 군집 내 첫 사건=단발, 이후=반복.
- 처치변수: `D_dep`(약세 억제 전체, placeholder 제외) ⊃ `D_dep_pure`(실개입 보도 없음) ⊃ `D_dep_hq`(신뢰도 medium 이상).

## 4. 권고 절차(본 연구용)
1. 두 명이 독립 코딩 → Cohen's κ 보고(방향·강도·official 각각).
2. 출처 위계: 기재부·한은 보도자료/입장문 > 한은 총재 기자간담회 속기 > 연합인포맥스·연합뉴스 > 종합일간지 > 영문 통신.
3. 발언 시각과 발언 직전 환율을 반드시 기록(연합인포맥스 "환율 장중 동향" 기사에 통상 포함).
4. 원화 강세 억제 발언도 동일 규칙으로 코딩(위약·대칭성 분석용).
